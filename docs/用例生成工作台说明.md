# 工作台操作说明

在仓库根目录，按 [README](../README.md) 安装依赖并启动服务。

1. 打开 http://127.0.0.1:8765 。
2. 上传 TXT、Markdown、DOCX 或文字型 PDF，选择本地模板或 AI 模型。
3. AI 模式需要在启动前配置环境变量，将需求文字发送到配置的服务。本地模板模式无需联网。
4. 查看每条用例的需求编号、原文与提取文本行号。检查步骤和预期，文档未明确的规则必须核实。
5. 修改用例并保存审核状态和备注，再导出 Excel、CSV、Markdown 或 JSON。

单文件不超过 3 MB，文字不超过 32000 字符。扫描 PDF 需要先 OCR。

生成的用例尚未执行，不会自动写脚本或测试用户系统。规则筛查和模型生成都有局限，审核不可省略。

上传文件与生成内容存入 `qa_workbench/artifacts/ai/case_jobs/`，不纳入 Git。

首页显示密钥是否被当前服务读取；如果修改了环境变量，应停止服务并在同一窗口重启。
